# 光伏旁路组重接线试算台（PV Bypass Rewiring Bench）

录入 3～9 个旁路组的开路电压 Voc 与短路电流 Isc、指定一份基线接线，
穷举搜索全部 1～3 串接线方案，按固定电气模型逐段精确求解全局最大功率点，
并在页面对比基线与最优接线的 P-V / I-V 曲线、峰值电压与功率；
试算记录持久化在 SQLite 中，可随时重开。
并提供**现场电流偏差诊断**：对历史记录提交现场实测 (V,I) 点，
比较健康假设与单组 Isc 退化假设，给出故障组定位或歧义/模型外结论。

- 后端：Python 3.11 · FastAPI · SQLite（标准库 `sqlite3`）
- 前端：原生 HTML / CSS / JavaScript（Canvas 手绘曲线，无框架、无构建步骤）
- 部署：Docker Compose 一键启动（试算台与现场诊断页同一服务）

## 一、快速启动（Docker Compose）

```bash
docker compose up --build -d
```

启动后访问：

- 应用页面：<http://localhost:8000/>
- **现场电流偏差诊断页（批量诊断入口）**：<http://localhost:8000/diagnose.html>
- 健康检查：<http://localhost:8000/api/health>
- OpenAPI 文档：<http://localhost:8000/docs>

诊断页底部“添加测点”可连续录入任意多个测点（**至少 3 个**，上限仅受
请求体大小约束）；提交后页面一次性返回**整批**测点的诊断结果：
顶部为总体结论框（无法确认异常 / 单组退化 / 多组歧义 / 模型外偏差），
其下是**全部测点**的健康理论电流、逐点偏差与容差判定表，再下是**每个
旁路组**的原 Isc、有效测点数、是否可行及逐组最小/最大可行 Isc 与
0.01 格点取值数。批量接口 `POST /api/trials/{id}/diagnose` 对合法批量
输入（如 9 组单串、1000 个测点）在服务端 5 秒内返回。

停止：

```bash
docker compose down          # 保留数据（数据在命名卷 pv_data 中）
docker compose down -v       # 连同试算数据一起删除
```

数据库文件位于容器内 `/srv/data/trials.db`，通过 compose 命名卷持久化。

### 不用 Docker 时的本地运行

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

然后同样打开 <http://localhost:8000/>（诊断页 <http://localhost:8000/diagnose.html>）。
可用环境变量 `PVBENCH_DB_DIR` 指定 SQLite 文件目录（默认 `./data/`）。

## 二、页面用法

1. **录入旁路组**：3～9 行，每行填
   - 组编号：1～32 个字符的非空串，**全局唯一**；
   - 开路电压 Voc：正数，**≤ 100 V**，至多两位小数；
   - 短路电流 Isc：正数，**≤ 30 A**，至多两位小数。
2. **指定基线接线**：1～3 条非空串；点击组编号芯片分配到各串，
   每组在基线中**恰好出现一次**（芯片在其他串会自动置灰、点击即移动）。
   - “一键：全部串联”可快速生成单串基线。
3. 点 **开始试算并保存**：
   - 左/右两栏分别展示基线与最优接线的串结构、峰值电压/电流/功率、开路电压；
   - 中部绘制两者的 **P-V 曲线**与 I-V 曲线（圆点为峰值，灰点为旁路拐点）；
   - 底部表格列出全部候选接线（功率降序，并列时串数少、字典序小者在前）；
   - 任何非法参数都会在按钮旁给出中文错误，且不会保存记录。
4. **历史记录**：页面底部列出全部试算；点击行即可**重开**（回填表单与结果），
   改动后再次试算会另存为新记录；可单条删除。

> 旧版本保存的结果快照（零电压电流取值偏低的）会在服务启动时按记录中
> 保存的输入自动重算并**就地校正**：不新增记录，编号、创建时间、输入、
> 峰值与候选排序均保持不变，仅零电压电流与 I-V 首点被修正；
> 重开记录或容器重启后返回的都是校正后的端点。

## 三、现场电流偏差诊断（历史记录）

诊断页：<http://localhost:8000/diagnose.html>（也可在首页历史记录表的
“现场诊断”链接或顶部入口进入，链接形如 `/diagnose.html?id=<记录编号>`，
打开后自动选中该记录）。

**操作步骤**

1. 在页面顶部下拉框选择一条历史试算记录；页面显示该记录的**基线开路电压**
   （实测电压的允许上限）。
2. 填写**电流容差**（有限非负数，可为 0），并录入**至少 3 个**实测点：
   - 实测端电压 V：有限非负数，**可为零**，且**不超过该记录基线开路电压**；
   - 实测电流 I：有限非负数；
   - 各测点电压**两两互异**。
   - 少量测点可用“＋ 增加测点”逐行填写；**批量测点**在“批量录入”文本框中
     每行粘贴一个 `V,I`（空白/逗号分隔，`#` 开头为注释），点
     “解析批量测点并填入上表”后提交（非法行会就地提示，不上送）。
3. 点 **提交诊断**，服务端将：
   - 从记录**保存的组参数与基线接线重新构建分段串曲线**求各测点理论电流
     （结果快照只是稀疏采样，**绝不用于插值**；拐点处精确选段，已达到
     某串开路电压的支路电流为 0）；
   - 比较两类假设：**健康状态**（参数不变）与**恰有一组 Isc 降为小于原值
     的正数**（0.01 网格，至多两位小数；Voc 与接线不变）；
   - 每个测点都满足 |实测电流 − 理论电流| ≤ 容差，该假设才算可解释。

**诊断结论（页面彩色结果框）**

| 结论 | 含义 |
| --- | --- |
| 无法确认异常 | 健康假设也能解释全部测点（此时即便某些退化假设数学上也满足，也不能判定为故障） |
| 定位到单组退化 | 仅同一组的 Isc 退化可解释：给出**组编号与可行 Isc 范围**（0.01 网格最小值～最大值及取值数） |
| 多组歧义 | 有多个组各自的单组退化假设都能解释全部测点：列出全部歧义组及其可行 Isc 范围 |
| 模型外偏差 | 健康与任何单组 Isc 退化均无法解释（如多组同时退化、Voc 漂移、接线改变等） |

页面同时给出：每个测点的健康理论电流、逐点偏差与是否在容差内；
以及每个组的原 Isc、有效测点数（该组所在串未达 Voc、仍贡献电流的测点数）、
是否可行与可行退化范围。诊断**只读**记录：不会新增、修改或删除任何试算，
也不影响原有试算与重开结果。记录不存在返回 `404`；测点或容差非法返回
`400` 中文错误。

**批量性能与算法**：固定测点电压下，总理论电流随某组退化候选 Isc
单调不下降（组被旁路、或其所在串已达到 Voc 时出现平台；达到串 Voc 的
零电流支路仍与实测逐点核对，不视为无约束）。因此每个测点允许的候选
构成一条连续 0.01 网格带：服务端对每个测点做两次“两端搜索”二分
（首个电流达下界、末个电流不超上界），再对全部测点取交集，得到每组的
最小/最大可行 Isc 与格点数；不逐档重建曲线枚举，也不对“全部点合格”
这一带外两侧皆假的谓词直接布尔二分。退化串曲线按网格下标懒构建并在
该组各测点间缓存复用，其余串贡献每组只算一次。零容差与旁路拐点沿用
同一套分段求值与浮点容差，判定与逐档枚举完全一致；9 组单串、1000 测点
量级的合法批量请求（无论宽容差全可行还是窄容差定位退化）均可在 5 秒内
完成。

## 四、电气模型

对组 g 采用固定线性旁路模型：

```
V_g(I) = max( Voc_g · (1 − I / Isc_g), 0 )
```

- 串联：串电压为各组电压之和 `V_S(I) = Σ_g V_g(I)`，
  随电流上升，Isc 较小的组依次在各自 Isc 处旁路，形成分段线性曲线；
- 并联：各串共用端电压 V，按每串的 V-I 关系反解电流后相加
  `I(V) = Σ_S I_S(V)`；
- 零电压取**最小可行电流**：每串为 `max(Isc)`（使串内全部组电压归零的
  最小电流，即受最大 Isc 组约束），并联为各串之和；
- 端电压达到某串开路电压时，该串电流为零。

取所有串旁路拐点（含 0 与各串开路电压）的并集排序后，每个电压区间内
总电流 `I(V)` 为线性、功率 `P(V)=aV−bV²` 为开口向下的二次函数；
因此逐段比较各拐点值与二次段顶点即可得到**精确**的全局最大功率点，
不依赖数值扫掠。

## 五、搜索与优选规则

枚举把 n 个组划分为 1、2、3 个非空块的**全部**接线
（n=9 时共 3281 种；串电压与组内顺序无关，故按组集合规范表示）。
每份接线计算全局峰值功率后，按以下顺序选出最优：

1. 全局最大功率 **最大**；
2. 功率相同 → **串数较少**者；
3. 仍相同 → 按“组内编号字典序、再串间字典序”的规范排列**较小**者；
4. 仍相同 → 峰值电压**较小**者。

## 六、HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/trials` | 提交试算：校验 → 全量搜索 → 保存，返回基线/最优结果与候选表 |
| `GET` | `/api/trials` | 试算记录列表 |
| `GET` | `/api/trials/{id}` | 获取单条记录（输入 + 完整结果，用于重开） |
| `DELETE` | `/api/trials/{id}` | 删除单条记录 |
| `POST` | `/api/trials/{id}/diagnose` | 现场电流偏差定位（只读该记录，不改动原试算） |
| `GET` | `/api/health` | 健康检查 |

`POST /api/trials` 请求体示例：

```json
{
  "name": "屋顶 A 区首轮",
  "groups": [
    {"id": "M1", "voc": "36.5", "isc": "8.2"},
    {"id": "M2", "voc": "36.5", "isc": "8.2"},
    {"id": "M3", "voc": "40.0", "isc": "6.0"},
    {"id": "M4", "voc": "30.0", "isc": "9.5"}
  ],
  "baseline": [["M1", "M2", "M3", "M4"]]
}
```

非法参数统一返回 `400 {"detail": "中文原因"}`，例如：

- 旁路组数量必须在 3～9 个之间；
- 组编号 'A' 重复，必须唯一；
- 组 A 的开路电压 Voc 必须是至多两位小数的正数；
- 组 A 的短路电流 Isc 不得超过 30；
- 基线接线中每组必须恰出现一次，缺失：C；
- 基线接线必须由 1～3 条串组成。

`POST /api/trials/{id}/diagnose` 请求体示例：

```json
{
  "tolerance": 0.1,
  "points": [
    {"v": 0.0,  "i": 9.45},
    {"v": 40.0, "i": 5.91},
    {"v": 80.0, "i": 3.42},
    {"v": 120.0, "i": 1.05}
  ]
}
```

- 至少 3 个测点且电压两两互异；V、I 均为有限非负数，
  V ≤ 该记录基线开路电压；`tolerance` 为有限非负数（可 0）。
- 测点数量没有额外上限，可整批提交（如 1000 个点）；
  响应中的 `points` 为与请求同序的逐点明细，`groups` 中每个可行组带
  `isc_min/isc_max/isc_candidates`（最小、最大可行 Isc 与 0.01 格点数）。
  用 curl 批量访问结果示例：

  ```bash
  curl -s http://localhost:8000/api/trials            # 查记录 id
  curl -s -X POST http://localhost:8000/api/trials/1/diagnose \
    -H 'Content-Type: application/json' \
    -d @batch-points.json | python3 -m json.tool      # batch-points.json 即
                                                      # tolerance + points[]
  ```
- 响应含 `verdict`：`unconfirmed`（无法确认异常）、`single_group`
  （单组退化，附 `explainable_groups` 及每组 `isc_min/isc_max/isc_candidates`）、
  `ambiguous`（多组歧义）、`out_of_model`（模型外偏差），以及中文 `message`、
  逐点理论电流/偏差表与各组可行性明细。
- 记录不存在返回 `404`；测点不足、电压越限/重复、负数或 NaN/Infinity、
  容差非法等返回 `400 {"detail": "中文原因"}`。诊断接口不写库。

## 七、目录结构

```
.
├── app/
│   ├── main.py          # FastAPI：路由、结果序列化、静态页与诊断 API
│   ├── model.py         # 电气模型、分段 MPP 精确求解、全接线枚举、任意测点理论电流
│   ├── diagnose.py      # 现场偏差定位：测点校验、健康/单组 Isc 退化假设（两端搜索求可行带）
│   ├── validation.py    # 入参校验（组数/编号/上下限/小数位/基线完整性）
│   ├── db.py            # SQLite 存取（JSON 快照，支持重开；诊断只读）
│   └── static/          # 原生前端（index / diagnose 两个页面 + styles / js，诊断页支持批量粘贴）
├── tests/               # 纯标准库验证脚本（不打入镜像）：
│   ├── bench_diagnose.py     # 两类千点批量场景耗时基准
│   ├── test_differential.py  # 两端搜索 vs 逐档枚举参考实现的随机差分
│   ├── test_edge_cases.py    # 零容差/拐点/Voc 零电流支路/夹零等边界
│   └── test_e2e.py           # DB→校验→诊断调用链、只读性与 400 错误
├── data/                # 本地运行时的 SQLite 目录（运行时生成）
├── Dockerfile
├── docker-compose.yml
└── requirements.txt
```

测试直接用系统 Python 3.11 运行（无需第三方依赖），例如
`python3 tests/test_differential.py`、`python3 tests/bench_diagnose.py 1000`。
